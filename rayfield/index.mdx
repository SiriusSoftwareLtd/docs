## Rayfield loadstring

This is the official loader. It always serves the current release, so the same line keeps working after updates.

```luau
local Rayfield = loadstring(game:HttpGet('https://sirius.menu/rayfield'))()
```

Only load Rayfield from `sirius.menu`. Copies hosted elsewhere can be out of date or changed. If it stops loading, check [status.sirius.menu](https://status.sirius.menu) or ask on [Discord](https://discord.sirius.menu).

For Rayfield Gen2, see [loading Gen2](/rayfield-gen2/getting-started).

Rayfield gives you a complete set of UI primitives for Roblox scripts. Windows, tabs, elements, notifications, themes — everything you need to ship a polished interface without building it yourself.
